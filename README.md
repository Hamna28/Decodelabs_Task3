# FLORA — Luxury Botanical Scented Candles 🕯️🌸

A responsive, single-page web application for **FLORA**, a luxury eco-friendly botanical candle brand. Built with semantic HTML5, modern CSS3, and vanilla JavaScript, this project features theme toggling, interactive product filtering, a slide-out shopping bag drawer, client-side form validation, and toast notifications.

---

## ✨ Features

* **🎨 Light & Dark Mode:** Toggle seamlessly between clean cream and deep dark themes with persistent `localStorage` support.
* **📱 Fully Responsive Design:** Clean layout optimized for mobile, tablet, and desktop viewports with a persistent navbar.
* **⚡ Dynamic Product Filtering:** Interactive category filters (`All`, `Floral`, `Woody`, `Fresh`) that keep items neatly centered across screens.
* **🛍️ Interactive Slide-Out Shopping Bag:** 
  * Add and remove items with real-time price totals and bag count badges.
  * Inline order checkout confirmation flow.
* **📂 Collapsible Accordion:** Expandable section detailing eco-friendly soy wax and essential oil highlights.
* **✉️ Contact Form Validation:** Instant client-side validation for required fields and valid email formatting.
* **🔔 Toast Notifications:** Non-intrusive notification banners when adding items to the bag.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessible markup.
* **CSS3:** Custom properties (variables), Grid layout, Flexbox, smooth transitions, and media queries.
* **JavaScript (ES6+):** Pure vanilla JavaScript for state management, DOM manipulation, navigation, and validation.
* **Typography:** [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) & [Montserrat](https://fonts.google.com/specimen/Montserrat) via Google Fonts.
